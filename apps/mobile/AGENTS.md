# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

## SDK version
- This project targets **Expo SDK 54** to match the App Store's current Expo Go.
- Install deps with `npx expo install` (NOT bare npm). Keep `legacy-peer-deps=true` in `.npmrc` (react-server-dom-webpack peer quirk).
- Do NOT upgrade Expo without also confirming Expo Go on the App Store supports the new SDK — mismatches show "Project is incompatible with this version of Expo Go".
